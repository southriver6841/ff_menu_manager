# 메뉴 관리 (ff_menu_manager)

FlaskFarm에 설치된 플러그인 메뉴를 화면에서 관리하는 플러그인입니다.

## 기능

| 메뉴 | 기능 |
|---|---|
| 메뉴 편집 | 대분류(상단 탭) > 중분류 > 소분류 3단계 편집. 탭 끌기로 대분류 순서 변경, 중분류는 아코디언으로 펼쳐 표시 이름 변경, 숨기기, 이동. "+ 중분류"로 직접 만든 중분류에 플러그인을 끌어 넣으면 소분류(하위 메뉴)가 됩니다. 시스템 > 확장 설정의 소분류도 순서 변경과 숨기기가 됩니다 |
| 플러그인 사용 | 플러그인 사용/미사용 (`config.yaml`의 `plugin_except_list`, 재시작 후 적용) |
| 전체 플러그인 목록 | 시스템 > 플러그인 > 전체 플러그인 목록 맨 위에 `catalog.yaml`의 "내 플러그인" 분류를 추가 (FF 파일은 수정하지 않고 메모리에서만 합침) |

## 동작 방식

- 메뉴 구성은 FlaskFarm의 `data/db/menu.yaml`에 저장합니다. 시스템 > 설정 > 메뉴 화면과 같은 파일입니다.
- FlaskFarm은 `menu.yaml`에 적힌 플러그인 `name`을 무시하고 플러그인 자체 이름을 씁니다. 그래서 이 플러그인이 메뉴를 만들 때 `name`(이름 변경)과 `hidden: true`(숨김)를 덧씌웁니다.
  - 이 플러그인을 지우면 이름 변경과 숨김은 풀리고, 폴더 구성만 남습니다.
- 저장할 때마다 이전 파일을 `menu.yaml.bak_*`, `config.yaml.bak_*`로 백업합니다(최근 10개).
- 직접 만든 중분류는 `menu.yaml`에 `uri: mm_group`으로 저장됩니다. FlaskFarm은 이 항목을 무시하고, 이 플러그인이 메뉴를 만들 때 확장 설정과 같은 하위 메뉴 형식으로 바꿔 끼웁니다. 이 플러그인을 지우면 그 안의 플러그인은 '미분류'로 돌아갑니다.
- "메뉴 숨기기"는 플러그인을 로딩한 채 메뉴에서만 감춥니다. "미사용"은 플러그인을 아예 로딩하지 않습니다.
