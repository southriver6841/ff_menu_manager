# 메뉴 관리 (ff_menu_manager)

FlaskFarm에 설치된 플러그인 메뉴를 웹 화면에서 정리하는 플러그인입니다.
`menu.yaml`을 직접 고치지 않고 끌어서 놓기만으로 메뉴 순서·분류·이름·숨김을 바꾸고, 플러그인 사용/미사용도 켜고 끌 수 있습니다.

## 주요 기능

| 메뉴 | 할 수 있는 일 |
|---|---|
| **메뉴 편집** | 대분류(상단 메뉴) 추가·삭제·이름 변경·순서 변경 / 플러그인을 다른 대분류로 이동 / 표시 이름 변경 / 메뉴에서 숨기기 / 직접 만든 중분류 안에 플러그인을 묶어 하위 메뉴(소분류)로 만들기 / 시스템 > 확장 설정의 항목 순서 변경·이름 변경·숨기기 |
| **플러그인 사용** | 플러그인을 아예 로딩하지 않도록 끄기(`config.yaml`의 `plugin_except_list`). FlaskFarm 재시작 후 적용 |
| **전체 플러그인 목록** | 시스템 > 플러그인 > 전체 플러그인 목록 맨 위에 `catalog.yaml`의 "내 플러그인" 분류를 추가 |
| **로그** | 이 플러그인의 동작 로그 |

## 설치

FlaskFarm의 **시스템 > 플러그인** 화면에서 아래 주소로 설치합니다.

```
https://github.com/southriver6841/ff_menu_manager
```

또는 FlaskFarm 플러그인 폴더(`data/plugins`)에 직접 받아도 됩니다.

```bash
cd <FlaskFarm 데이터 폴더>/plugins
git clone https://github.com/southriver6841/ff_menu_manager.git
```

설치 후 FlaskFarm을 재시작하면 상단 메뉴에 **메뉴 관리**가 생깁니다.

> 업데이트: 시스템 > 플러그인 화면에서 업데이트하거나, 폴더에서 `git pull` 후 재시작합니다.

## 메뉴 구조 이해하기

FlaskFarm 메뉴를 3단계로 다룹니다.

```
상단 메뉴바
├─ 대분류 (예: "다운로드")            ← 편집 화면의 탭
│   ├─ 중분류 (예: 플러그인 A)         ← 탭 안의 한 줄
│   ├─ 중분류 (직접 만든 묶음 "토렌트") ← 보라색 줄
│   │   ├─ 소분류 (플러그인 B)
│   │   └─ 소분류 (플러그인 C)
│   └─ ── 구분선 ──
└─ 대분류 "시스템"
    └─ 확장 설정                       ← 보라색 줄, 각 플러그인 설정 화면이 소분류
```

편집 화면에 보이는 줄의 종류:

| 표시 | 뜻 | 할 수 있는 일 |
|---|---|---|
| 플러그인 이름 | 설치된 플러그인 | 이동, 이름 변경, 숨기기 |
| `미사용` 배지 | 플러그인 사용에서 꺼 둔 플러그인 | 위와 같음 (재시작 후 메뉴에서 빠짐) |
| `기본/링크` 배지 | FlaskFarm 기본 메뉴나 외부 링크 | 이동, 이름 변경, 숨기기 |
| `중분류` 배지 (보라색) | 직접 만든 묶음 | 이름 변경, 전체 숨기기, 이동, 해제, 안에 플러그인 넣기 |
| `확장 설정` 배지 (보라색) | 시스템 > 확장 설정 | 이름 변경, 전체 숨기기, 이동, 안의 항목 순서 변경·이름 변경·숨기기 |
| `── 구분선 ──` | 메뉴 사이 구분선 | 이동 |
| `미분류` 탭 (기울임) | `menu.yaml`에 없는 플러그인 | 다른 탭으로 옮기기, 숨기기 |
| 탭 이름 옆 `↗` | 하위 메뉴 없는 상단 바로가기 | 이름 변경, 순서 변경 |

## 메뉴 편집 사용법

**메뉴 관리 > 메뉴 편집** 화면입니다. 화면 위쪽 어두운 막대가 실제 상단 메뉴바이고, 그 아래 흰 패널이 선택한 대분류의 내용입니다.

> 모든 변경은 **저장** 버튼을 눌러야 반영됩니다. 저장 후 페이지를 **새로고침**하면 상단 메뉴가 바뀝니다.
> 저장 전에 되돌리고 싶으면 **다시 불러오기**를 누르세요.

### 1. 대분류(상단 탭)

| 하고 싶은 일 | 방법 |
|---|---|
| 순서 바꾸기 | 탭을 좌우로 끌어서 놓기 |
| 새로 만들기 | 맨 오른쪽 **+ 대분류** 클릭 → 이름 입력 |
| 이름 바꾸기 | 탭을 선택하고 패널 위쪽 입력칸에서 수정 |
| 삭제 | 탭 선택 → **대분류 삭제**. 안의 플러그인은 `미분류`로 돌아갑니다 |

- 기본 메뉴·링크·확장 설정이 들어 있는 대분류는 삭제할 수 없습니다. 먼저 그 항목을 다른 대분류로 옮기세요.
- 비어 있는 대분류는 저장할 때 자동으로 빠집니다.
- `미분류` 탭은 이름을 바꾸거나 삭제할 수 없습니다.

### 2. 중분류(탭 안의 줄)

줄을 클릭하면 아코디언처럼 펼쳐져 세부 설정이 나옵니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 순서 바꾸기 | 줄의 머리(☰ 부분)를 위아래로 끌기 |
| 다른 대분류로 옮기기 | 줄을 끌어서 **위쪽 다른 탭 위에** 놓기 (끄는 동안 놓을 수 있는 탭에 점선 표시, 위에 올리면 초록색) |
| 다른 대분류로 옮기기 (휴대폰) | 줄을 펼쳐 **이동** 목록에서 대상 대분류 선택 |
| 표시 이름 바꾸기 | 펼쳐서 **표시 이름** 수정. 비워 두면 원래 이름으로 돌아갑니다 |
| 메뉴에서 숨기기 | 펼쳐서 **메뉴에서 숨기기** 체크. 줄에 `숨김` 배지와 취소선이 표시됩니다 |

- 플러그인을 펼치면 **하위 페이지** 목록도 볼 수 있습니다(플러그인이 가진 메뉴 페이지).
- `미분류` 탭에서는 이름을 바꿀 수 없습니다. 대분류로 옮긴 뒤 바꾸세요. 숨기기는 가능합니다.
- `미분류`로는 플러그인만 옮길 수 있습니다.

### 3. 소분류 만들기 (중분류로 묶기)

여러 플러그인을 하나의 하위 메뉴로 묶을 수 있습니다.

1. 대분류 탭을 선택하고 **+ 중분류** 클릭 → 보라색 "새 중분류" 줄이 생깁니다.
2. **중분류 이름**에 이름을 입력합니다(예: `토렌트`).
3. 묶을 플러그인 줄을 끌어서 보라색 중분류 안의 점선 상자에 놓습니다.
4. **저장** → 새로고침.

상단 메뉴에서 `대분류 > 토렌트 > 플러그인` 형태로 표시됩니다.

- 소분류에는 **플러그인과 구분선만** 넣을 수 있습니다.
- 소분류를 다시 밖으로 빼려면 끌어서 꺼내거나, **이동**에서 `(중분류 밖으로)`를 고르세요.
- **중분류 해제**를 누르면 묶음만 없어지고 안의 플러그인은 그 자리에 남습니다.
- **중분류 전체 숨기기**로 묶음째 감출 수 있습니다.
- 비어 있는 중분류는 저장할 때 빠집니다.

### 4. 확장 설정

시스템 대분류의 보라색 **확장 설정** 줄을 펼치면 각 플러그인의 설정 화면이 소분류로 나옵니다.

- 안에서 끌어 **순서 변경**, 펼쳐서 **표시 이름 변경**, **숨기기**가 됩니다.
- 확장 설정 안의 항목은 밖으로 꺼낼 수 없고, 밖의 항목을 넣을 수도 없습니다.
- 아무것도 바꾸지 않으면 FlaskFarm 기본 동작(새로 설치한 플러그인의 설정도 자동 표시)을 그대로 유지합니다.

### 5. 상단 바로가기 (`↗` 탭)

하위 메뉴 없이 상단에 바로 붙은 메뉴입니다. 탭을 선택해 이름을 바꾸거나 끌어서 순서를 바꿀 수 있습니다. 이 탭으로는 다른 항목을 옮겨 넣을 수 없습니다.

### "메뉴 숨기기"와 "미사용"의 차이

| | 메뉴 숨기기 (메뉴 편집) | 미사용 (플러그인 사용) |
|---|---|---|
| 플러그인 로딩 | 계속 로딩됨 (스케줄러, API 등 동작) | 로딩 안 됨 |
| 메뉴 표시 | 안 보임 | 안 보임 |
| 주소로 직접 접속 | 가능 | 불가 |
| 적용 시점 | 저장 후 새로고침 | FlaskFarm 재시작 후 |
| 기록 위치 | `menu.yaml`의 `hidden: true` | `config.yaml`의 `plugin_except_list` |

## 플러그인 사용 / 미사용

**메뉴 관리 > 플러그인 사용** 화면입니다.

1. 끄고 싶은 플러그인의 **사용** 스위치를 끕니다.
2. **저장**을 누릅니다.
3. FlaskFarm을 **재시작**합니다.

- **현재 상태** 열의 `로딩됨` / `로딩 안 됨`은 지금 실행 중인 상태입니다. 스위치와 다르면 `재시작 필요`가 표시됩니다.
- 이 플러그인(메뉴 관리) 자신은 끌 수 없습니다(`항상 사용`).
- `config.yaml`에서는 `plugin_except_list` 한 줄만 고칩니다. 다른 설정과 주석은 그대로 둡니다.

## 전체 플러그인 목록에 '내 플러그인' 추가

이 플러그인이 로딩되면 **시스템 > 플러그인 > 전체 플러그인 목록** 맨 위에 `catalog.yaml`에 적힌 분류가 추가됩니다.

```yaml
# catalog.yaml
- name: "내 플러그인"
  list:
  - title: "메뉴 관리"
    package_name: "ff_menu_manager"
    developer: "southriver6841"
    home: "https://github.com/southriver6841/ff_menu_manager"
    description: "플러그인 메뉴 폴더/이동/이름 변경/숨기기, 사용·미사용 관리"
```

- FlaskFarm 기본 목록에 이미 있는 `package_name`은 중복으로 넣지 않습니다.
- FlaskFarm 파일은 고치지 않고 메모리에서만 합칩니다. 그래서 FlaskFarm 업데이트에 영향을 주지 않습니다.
- 항목을 추가·수정하려면 `catalog.yaml`을 고친 뒤 FlaskFarm을 재시작하세요.

## 동작 방식

- 메뉴 구성은 FlaskFarm의 `data/db/menu.yaml`에 저장합니다. **시스템 > 설정 > 메뉴** 화면이 쓰는 파일과 같습니다.
- FlaskFarm은 `menu.yaml`에 적힌 플러그인 `name`을 무시하고 플러그인 자체 이름을 쓰며, 숨김 기능도 없습니다. 그래서 이 플러그인이 FlaskFarm의 메뉴 생성(`MenuManager.init_menu`)에 끼어들어 `name`(이름 변경)과 `hidden: true`(숨김)를 덧씌웁니다.
- 직접 만든 중분류는 `menu.yaml`에 `uri: mm_group`으로 저장됩니다. FlaskFarm은 이 항목을 모르는 항목으로 무시하므로, 이 플러그인이 메뉴를 만들 때 확장 설정과 같은 하위 메뉴 형식으로 바꿔 끼웁니다.
- `미분류`에서 숨긴 플러그인은 `숨긴 메뉴`라는 대분류에 `hidden: true`로 저장됩니다(메뉴에는 보이지 않음).
- 메뉴를 만드는 중 오류가 나도 FlaskFarm 기본 메뉴는 그대로 보입니다(오류는 로그에 기록).

저장된 `menu.yaml` 예시:

```yaml
- name: 다운로드
  list:
  - uri: ff_plugin_a
    name: 내가 바꾼 이름
  - uri: mm_group
    name: 토렌트
    list:
    - uri: ff_plugin_b
    - uri: ff_plugin_c
  - uri: ff_plugin_d
    hidden: true
```

### 이 플러그인을 지우면

- 이름 변경과 숨김은 풀리고, 대분류 구성과 순서만 남습니다.
- 직접 만든 중분류 안의 플러그인은 `미분류`로 돌아갑니다.
- `plugin_except_list`(미사용)는 `config.yaml`에 남아 계속 적용됩니다. 다시 쓰려면 `config.yaml`에서 지우세요.

## 백업과 되돌리기

저장할 때마다 이전 파일을 같은 폴더에 백업합니다(파일마다 최근 10개 유지).

- `data/db/menu.yaml.bak_YYYYMMDD_HHMMSS_...`
- `config.yaml.bak_YYYYMMDD_HHMMSS_...`

되돌리려면 원하는 백업 파일을 `menu.yaml`(또는 `config.yaml`)로 복사한 뒤 FlaskFarm을 재시작합니다.

```bash
cd <FlaskFarm 데이터 폴더>/db
cp menu.yaml.bak_20261117_120000_000000 menu.yaml
```

## 자주 묻는 질문

**저장했는데 메뉴가 그대로예요.**
브라우저를 새로고침하세요. 저장하면 서버 쪽 메뉴는 바로 다시 만들어지지만, 이미 열린 페이지의 상단 메뉴는 새로고침해야 바뀝니다.

**미사용으로 바꿨는데 메뉴에 그대로 있어요.**
미사용은 FlaskFarm을 재시작해야 적용됩니다.

**새로 설치한 플러그인은 어디에 나오나요?**
`미분류` 탭에 나옵니다. 원하는 대분류 탭 위로 끌어 놓고 저장하세요.

**시스템 > 설정 > 메뉴 화면과 같이 써도 되나요?**
같은 `menu.yaml`을 씁니다. 그 화면에서 직접 고칠 때는 이 플러그인 전용 항목(`uri: mm_group`, `hidden: true`, 플러그인의 `name`)을 지우지 않도록 주의하세요. 한쪽에서 저장한 뒤 다른 쪽 화면은 다시 불러오고 편집하세요.

**휴대폰에서 끌어서 놓기가 잘 안 돼요.**
각 줄을 펼쳐 **이동** 목록을 쓰세요.

## 개발 / 테스트

FlaskFarm 없이 순수 로직만 테스트합니다.

```bash
python -m pip install pyyaml pytest
python -m pytest -q
```

| 파일 | 역할 |
|---|---|
| `setup.py` | 플러그인 등록, 메뉴 정의 |
| `mod_main.py` | 화면 처리, 명령(`load` / `save_menu` / `set_enabled`), 훅 설치 |
| `menu_model.py` | `menu.yaml` ↔ 편집 화면 상태 변환 |
| `menu_override.py` | FlaskFarm이 만든 메뉴에 이름 변경·숨김·중분류 적용 |
| `menu_hook.py` | `MenuManager.init_menu` 감싸기 |
